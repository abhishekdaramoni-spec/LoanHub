# LoanSphere - Banking Loan Management System

LoanSphere is a premium digital banking and loan management platform designed with modern glassmorphism aesthetics, a mobile-first responsive layout, and robust security protocols. It utilizes Python Flask for the backend, SQLAlchemy ORM, and supports MySQL or PostgreSQL databases for production deployment.

---

## 🚀 Deployment on Render

This project is configured for one-click deployment to **Render** using the provided `render.yaml` blueprint.

### Environment Secrets
Ensure the following variables are configured in the Render Dashboard or environment settings:
- **`SECRET_KEY`**: A unique secure string for sessions encryption (automatically generated by Render if not provided).
- **`DATABASE_URL`**: Connection URI (MySQL or PostgreSQL). Example: `mysql+pymysql://user:pass@host/dbname` or `postgresql://user:pass@host/dbname`.
- **`PORT`**: Set to `5000` (automatically read by the app launcher).

### Steps to Deploy
1. Push this repository to your GitHub account.
2. In the Render Dashboard, click **New +** and choose **Blueprint**.
3. Link your GitHub repository.
4. Render will automatically read `render.yaml` and provision a Web Service running on Gunicorn.

## 🛠️ Local Installation & Running

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Configure Database (Optional)
If a remote MySQL database is not connected, the application will automatically fall back to creating and using a local SQLite database (`database/loansphere.db`).

If connecting to MySQL locally, set your env variables:
```bash
# Windows cmd
set DATABASE_URL=mysql+pymysql://root:password@localhost/loansphere_db

# Windows PowerShell
$env:DATABASE_URL="mysql+pymysql://root:password@localhost/loansphere_db"
```

### 3. Start the Web Server
Launch the application locally:
```bash
python app.py
```
Open **[http://localhost:5000](http://localhost:5000)** in your browser.
